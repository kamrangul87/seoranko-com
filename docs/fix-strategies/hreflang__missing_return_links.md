# hreflang__missing_return_links

Tier: A

Research title: hreflang__missing_return_links (topic 46).

## what's actually wrong

Page A declares an hreflang alternate pointing at Page B, but Page B does not
point back at A — so the annotation for that pair is ignored.

## threshold

A declared alternate pair is non-reciprocal.

Two distinct conditions, and they are not the same finding:

| Condition | Source | Severity |
|---|---|---|
| A points at B; B declares no annotation for A | G6 | high — the pair is ignored |
| A does not declare itself (missing self-reference) | G5 | high |
| A points at B; B points at a *different* URL for A's locale | G6 | high — conflicting cluster |
| cluster is not fully all-to-all, but every declared pair is reciprocal | G8 | **none.** Permitted for large sites |

**Reporting is per pair, not per site** (G7). Google can still process other
correctly reciprocal pairs, so one broken pair does not invalidate the
cluster — and reporting it as a site-wide failure overstates the consequence.

## detect

1. Collect annotations from **all three methods** — HTML `<link
   rel="alternate">`, the HTTP `Link` header, and the XML sitemap (G1). An
   annotation present in any one of them counts.
2. Build the declared graph: for each URL, the set of (locale, target) pairs.
3. For each declared edge A→B, fetch B and check for an edge B→A.
4. Check each page declares itself (G5).
5. Compare the clusters declared by each method. Divergence is a separate
   finding (G4).
6. Re-fetch per topic 68 before raising.

Failing to check all three methods is the principal false-positive source in
this topic.

## fix

Add the missing reciprocal annotation to the target page, using the method the
site already uses.

Deterministic where:

- the locale of the source page is established from an authoritative repo
  source — a route locale segment or i18n config (same rule as topic 34), not
  guessed
- the target page exists, returns 200, and is not `noindex` (topic 48)
- the site's declaration method is unambiguous

Where the locale of either page cannot be established from the repo, the fix
is `human-review` — adding an annotation with a guessed locale creates a
wrong cluster, which is worse than an incomplete one.

## postcondition

Live: for every declared edge A→B in the served response, a reciprocal edge
B→A exists in B's served response, via any of the three methods. Asserted via
a code path separate from the executor.

## idempotent?

Yes.

## risk / blast radius

hreflang annotations are normally generated by a shared layout or i18n helper,
so a fix applies across every localized page. Where generated at build time,
fix the generator, not the output.

Adding a wrong annotation is worse than a missing one: it tells Google to
serve the wrong locale to real users.

## rollback

Revert.

## verdict

`auto-fixable` where both locales are established from the repo, the target is
healthy, and the declaration method is unambiguous.

`human-review` where locale must be inferred, where the three methods declare
different clusters, or where the cluster spans domains (G3) — the other domain
may not be under the user's control.

## false-positive guards

| # | Guard | Action |
|---|---|---|
| 1 | Reciprocal annotation exists in a header or the sitemap but not in HTML | **not missing** (G1). Check all three before raising |
| 2 | Cluster is not all-to-all but every declared pair is reciprocal | permitted (G8). Never raise |
| 3 | One broken pair reported as a whole-cluster failure | overstated (G7). Report per pair |
| 4 | Locale of either page inferred rather than repo-sourced | never auto-fix. `human-review` |
| 5 | Alternate is on another domain | G3 permits it, but reciprocity may be outside the user's control. `human-review` |
| 6 | Target returns non-200 or is `noindex` | topic 48 first — a broken target is the prior problem |
| 7 | Annotation sits outside a well-formed `<head>` | G24 — topic 29 is the cause |
| 8 | Annotation combines hreflang with `media` | separate error (G23) |
| 9 | Annotations generated client-side | assess the served response (topic 67) |

### Explicitly rejected

- **Raising a finding from HTML alone.** G1 — three methods are equal.
- **Guessing a page's locale to complete a cluster.**
- **Reporting a non-reciprocal pair as a site-wide hreflang failure.** G7.
- **Requiring all-to-all clusters.** G8 permits the hub pattern.
- **The "prevents third parties claiming localized status" rationale.**
  Unsourced.

## fixture

A→B with no B→A; A→B with B→A present only in the sitemap; a page with no
self-reference; a hub-pattern cluster where every pair is reciprocal; A→B
where B→A points at a different URL; a cross-domain alternate; an annotation
in `<body>`.

CI asserts: raised for the first, third and fifth; **suppressed** for the
second and fourth; `human-review` for the sixth; routed to topic 29 for the
seventh.
