## what's actually wrong

A page receives impressions in Search but has no inbound crawlable internal
links — so the site is getting value from a page its own architecture ignores.

## threshold

Both conditions, proven independently:

1. the URL appears in Search Analytics with impressions above a floor, over a
   stated date range (B20–B22)
2. the URL has **zero inbound crawlable internal links** — `<a href>` with a
   resolvable URI (topic 43, N1, N3)

The impressions floor is a **product decision**, not a Google threshold. There
is no published figure, and B22 means the row set is already truncated to top
rows, so any floor sits on top of an unknown cut.

This is the most useful topic in the block, because unlike 56 and 57 it
combines a GSC signal with a mechanically provable site defect, and the fix is
deterministic.

## detect

1. Query Search Analytics page rows for the date range. Prefer finalized data
   (B26).
2. **Normalise canonically** (B23) before matching against crawled URLs.
3. Compute inbound crawlable internal links per URL from the link graph.
4. Impressions above floor **and** zero inbound crawlable links → finding.
5. Record the date range and row coverage (B21, B22, B25).

## fix

Add an inbound internal link from a relevant page.

**Choosing the source page and the anchor text is content and editorial
judgement**, so the agent does not author it. What it contributes mechanically:

- candidate source pages, ranked by content similarity to the target — the
  same similarity machinery used in the topic 41 successor check
- the target's own `<title>` as a starting anchor-text value, drawn from the
  page rather than generated
- N6 as the standard: anchor text should be descriptive and inside the anchor

One case **is** fully deterministic and should be separated out: where the
page is reachable only via an `onclick` handler or `javascript:` href
(topic 43 guard C), converting it to a real `<a href>` requires no editorial
decision at all. That is auto-fixable.

## postcondition

Live: the target URL has at least one inbound `<a href>` from another page of
the site, present in the served HTML of that page. Asserted by re-crawling the
link graph, not by GSC.

## idempotent?

Yes.

## risk / blast radius

Adding a link to a shared nav or footer puts it on every page — usually not
what a single orphaned page warrants. Prefer a body link on a related page and
say so in the proposal.

## rollback

Revert.

## verdict

`connection-required`.

`auto-fixable` only for converting a non-crawlable link into a real `<a href>`
(topic 43 guard C).

`human-review` for adding a new link, since source page and anchor text are
editorial.

No GSC connection → silent. Note that topic 43 still detects the orphan
without GSC; this topic only adds the impressions evidence.

## false-positive guards

| # | Guard | Action |
|---|---|---|
| 1 | Matched without canonical normalisation | false results (B23) |
| 2 | Impressions floor presented as a Google threshold | it is a product decision. Label it |
| 3 | Page is deliberately unlinked — campaign or landing page | `human-review`. Often intentional |
| 4 | Page is reachable via a JS-rendered real `<a href>` | **not** orphaned (N4). Never raise |
| 5 | Page has external inbound links | not detectable — no backlink API. State the limitation |
| 6 | Absence from the row set read as zero impressions | B22. Never infer zero |
| 7 | Link proposed into shared navigation | usually disproportionate. Prefer a body link |
| 8 | Anchor text generated by a model | rejected. Use the target's own title as a candidate |
| 9 | No GSC connection | silent; topic 43 still applies |

### Explicitly rejected

- **Generating anchor text or link copy with a language model.**
- **Adding links into shared navigation automatically.**
- **Any "internal link equity" or PageRank framing.** Unsourced.
- **Inferring zero impressions from an absent row.** B22.
- **Presenting the impressions floor as sourced.**

## fixture

A page with impressions and zero inbound crawlable links; with impressions and
reachable only via `onclick`; with impressions and reachable via a JS-rendered
`<a href>`; a campaign landing page with impressions and no links; `/page/` in
GSC matching `/page` in the crawl; no GSC connection.

CI asserts: `human-review` with ranked candidate sources for the first;
**auto-fix** for the second; **nothing** for the third; `human-review` flagged
as possibly intentional for the fourth; matched after normalisation for the
fifth; silent for the sixth.
